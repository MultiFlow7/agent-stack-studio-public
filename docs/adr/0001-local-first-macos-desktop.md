# ADR 0001：采用本地优先的 macOS 桌面架构

- 状态：已接受
- 日期：2026-08-19

## 背景

产品用于个人在本机搭建和实验 Agent Stack。团队协作和共享已经由 Multica 提供。如果再建设共享 Web 控制台、中心数据库和 Runtime 注册服务，会重复职责并增加部署和权限复杂度。

## 决策

第一版只支持 macOS，采用 Electron 桌面应用。所有产品数据和运行默认保存在本机，不需要浏览器、localhost 或团队服务器。团队共享通过显式 Multica Connector 完成。

## 结果

优点：

- Cordis、Node.js Harness、本地 CLI 和文件系统集成简单。
- 本地实验数据和密钥边界清楚。
- 用户不需要部署基础设施。
- 与 Multica 的职责不重叠。

代价：

- 需要处理 macOS 签名、公证和本地数据迁移。
- 多台设备之间不会自动同步。
- Electron 安装体积大于原生 Swift 应用。

上述代价在第一阶段可以接受。未来若增加其他平台，需要新的 ADR，不能默认扩展为共享 Web 服务。
